# fastcart-server

Собственный бэкенд для fastcart: баннеры (hero-слайдер на главной) и заказы.
Каталог товаров, пользователи и логин остаются на основном бэкенде
(`fastcard-1-o23z` на Render) — этот сервис его не заменяет, а дополняет.

## Стек

- Node.js + TypeScript
- Express
- PostgreSQL + [Drizzle ORM](https://orm.drizzle.team/) (без Prisma — его "движок"
  для миграций блокируется Windows Application Control Policy на этой машине,
  Drizzle работает через чистый JS-драйвер `pg` без нативных бинарников)

## Как устроена авторизация

Токен (JWT) выдаёт **основной** бэкенд при логине/регистрации. Этот сервис
не может проверить его подпись — у него нет секретного ключа основного
бэкенда. Поэтому `src/middleware/auth.ts` только **декодирует** токен
(`jwt.decode`, не `jwt.verify`) и достаёт из него `id` и `role`.

Это осознанный компромисс для учебного проекта: теоретически можно собрать
токен с любым `id`/`role` без пароля. Для настоящего продакшена нужно либо
получить общий секретный ключ от того, кто держит основной бэкенд (тогда
здесь тоже можно будет использовать `jwt.verify`), либо перевести всю
авторизацию на один бэкенд.

## Запуск локально

```bash
npm install
cp .env.example .env   # и вписать свой DATABASE_URL
npm run db:push        # создать таблицы в базе
npm run dev             # http://localhost:4000
```

## Переменные окружения

| Переменная        | Описание                                              |
| ------------------ | ------------------------------------------------------ |
| `DATABASE_URL`      | Строка подключения к PostgreSQL                        |
| `PORT`              | Порт сервера (Render подставляет свой автоматически)   |
| `FRONTEND_ORIGIN`   | Домен(ы) фронта, которым разрешён доступ (CORS), через запятую |

## API

### Баннеры

- `GET /api/banners` — публичный список активных баннеров, по `sortOrder`
- `POST /api/banners` — создать (только `Admin`/`SuperAdmin`)
- `PUT /api/banners/:id` — обновить (только `Admin`/`SuperAdmin`)
- `DELETE /api/banners/:id` — удалить (только `Admin`/`SuperAdmin`)

Картинка — просто `imageUrl` (внешняя ссылка). Своего хранилища файлов пока
нет: на бесплатном тарифе Render файловая система эфемерна и не переживает
редеплой, поэтому загрузка файлов сюда пока не добавлена.

### Заказы

Все роуты требуют `Authorization: Bearer <token>`.

- `POST /api/orders` — создать заказ (данные доставки + список товаров-снимков)
- `GET /api/orders` — список заказов текущего пользователя
- `GET /api/orders/:id` — один заказ текущего пользователя

## Полезные команды

- `npm run db:generate` — сгенерировать SQL-файл миграции из схемы (для истории изменений)
- `npm run db:push` — применить текущую схему к базе напрямую (быстро для разработки)
- `npm run db:studio` — открыть Drizzle Studio (веб-интерфейс для просмотра таблиц)
- `npm run build` / `npm run start` — собрать и запустить прод-версию
